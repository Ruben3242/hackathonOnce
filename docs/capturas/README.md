# Capturas de la interfaz

Pantallas del Transcriptor B8 por si no se puede arrancar Node. El programa se abre con `arrancar.bat` → http://localhost:3000

| Archivo | Qué se ve |
|---------|-----------|
| `01-escritorio.png` | Inicio: subida, ejemplos 1–6, corregir pieza, tablero vacío |
| `02-tablero-2.png` | Tablero 2 cargado: grid, braille B8, voz, jugadas |
| `03-movil.png` | Vista `/movil` en tamaño de teléfono: cámara/foto/galería |
| `04-ayuda.png` | Manual de uso |
| `05-instalar.png` | Instalar en el teléfono (QR y URL LAN) |
| `06-kaggle-1.png` | Foto Kaggle 1, modelo local: 13 piezas, lectura exacta (64/64) |
| `07-kaggle-2.png` | Foto Kaggle 2: otra posición, 11 piezas, también exacta. El tablero, el braille y la voz cambian |

En `05-instalar.png` la IP y el QR son de un PC de ejemplo (red local), no un servidor público. En cada máquina saldrá otra IPv4 (`/instalar` o `ipconfig`).
